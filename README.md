Data Documentation, Governance & Lineage Solution - **Automated**, Agnostic, Standalone

Marvim is an Acronym that stands for: **M**aster, **A**utomated, **R**epository for **V**isual **I**ntelligent **M**etadata management

Marvim is Self-documenting, when used in combination with Anatella/TIMi (this is a totally optional combination).

Marvim is Standalone: it does not rely on any third-party component or technology.

**Note**:

The HugeRTE library is required to run Marvim. For your convenience, this library is available inside the file HugeRTE.zip in the root of the project. Please unzip the HugeRTE.zip inside the directory www/marvim/HugeRTE before running Marvim.
